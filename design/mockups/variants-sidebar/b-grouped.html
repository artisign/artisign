B · Grouped variants

One level: main screen + flat variant group.

Kinds

state — same screen, different data (two-parents, -empty)
overlay — sheet / snackbar over a base (sheet-leave)

Sequences stay plain flows; sheet-leave-confirm is just another flat overlay of family-l2.

What changes

Easier — 197 rows collapse to 46. The count badge tells you at a glance which screens carry many variants (calendar-month 7 + 30).

Easier — filter still hits variants; the dimmed context row keeps the relation visible.

Harder — no depth: leave → leave-confirm / -dissolve / -no-transfer flatten into one list of 8.

Harder — a 37-variant group is a long unfiltered list; needs the kind badge to sub-filter.

Flow & Board stay intact

Every row remains a real screen: clickable, commentable, flow endpoint. The relation is a stored variant-of field, not a name prefix (calendar-sheet-* has none). Group toggle falls back to today’s list.

Numbers in the hint
