Release notes of the version you run and the one before it.

2.1.12026-10-21Installed

Fixed

  • artisign update now always restarts the running Artisign (same port, same open projects) after installing, and /health reports the version the process started with.

2.1.02026-10-21

One install path and a per-call project: Artisign is installed once with npm install -g artisign, connects to your AI tools itself, and every tool call names its project.

Changed

  • Breaking:/mcp no longer reads ?project=. Every tool except list_projects, init_project and get_guide takes a required project input.
  • The install path is npm install -g artisign, then artisign; the README and the tutorial start from it.

Added

  • artisign setup connects Claude Code, Claude Desktop, Cursor, Codex CLI, VS Code and opencode with one user-level artisign entry each.
  • artisign update installs the latest version, re-pins every existing entry in your AI tools and restarts a running Artisign on its port.
  • Artisign checks the npm registry for a newer release at most once every 24 hours; turn it off with ARTISIGN_NO_UPDATE_CHECK=1.
