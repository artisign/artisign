Added
  • artisign setup connects Claude Code, Claude Desktop, Cursor, Codex CLI, VS Code and opencode with one user-level artisign entry each. (CHR-833)
  • artisign update installs the latest version, re-pins every existing entry in your AI tools and restarts a running Artisign on its port. (CHR-881)
  • Artisign checks the npm registry for a newer release at most once every 24 hours; turn it off with ARTISIGN_NO_UPDATE_CHECK=1.
